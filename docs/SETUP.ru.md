# Сборка и настройки

[← Herdr Tavern](../README.ru.md) · [English](SETUP.md) · Русский

## Требования

- **macOS 14 или новее.** Сборка рассчитана на архитектуру текущей машины, не является универсальной.
- **Xcode Command Line Tools** с `xcrun swiftc`.
- **Rust stable через rustup** и Cargo.
- **Herdr для работы приложения.** Если он отсутствует, Tavern предлагает установку; ручная установка также поддерживается. Текущие функции проверялись с версией **0.9.4**; совместимость с произвольной новой версией не гарантируется.
- **Локальный сертификат подписи** — настройка описана ниже.

Herdr не входит в комплект приложения. Сами программы агентов и доступ к моделям настраиваются отдельно. Python и генератор изображений для обычной сборки не нужны.

Все поставляемые шрифты включены в `resources/Fonts/` и копируются при сборке в `.app` без скачивания шрифтов или чтения локально установленных. Tavern загружает их из ресурсов при запуске; ручная установка шрифтов не нужна. Терминал использует Iosevka Custom **34.9.0** (Medium, Bold, Medium Oblique и Bold Oblique) и Symbols Nerd Font; декоративные интерфейсные шрифты также входят в комплект. Системные резервные шрифты Menlo и emoji по-прежнему предоставляет macOS.

## Локальная подпись

До первой сборки создай в **Keychain Access** самоподписанный сертификат **Herdr Tavern Local Signing** типа **Code Signing**. Он должен иметь приватный ключ; настрой доверие только для Code Signing и разреши `/usr/bin/codesign` использовать ключ. Без пригодного сертификата сборка останавливается до компиляции.

Сохраняй этот сертификат при обновлениях: пересоздание даже с тем же именем меняет идентичность приложения и может потребовать повторно выдать разрешения macOS. Приватный ключ и его экспорт не должны попадать в репозиторий. Локальная подпись не заменяет Developer ID и нотариализацию публичного релиза.

## Сборка и запуск

Выполняй команды из корня репозитория, не из `docs/`:

```sh
./build.sh
open "build/Herdr Tavern.app"
```

Первой сборке может понадобиться сеть для загрузки Cargo-зависимостей. При заполненном кэше можно использовать `CARGO_NET_OFFLINE=true ./build.sh`. Скрипт собирает приложение и проверяет подпись, но не запускает тесты.

Сборка использует сохранённые runtime PNG и не требует генерации изображений. Новый bundle собирается в чистом временном каталоге и заменяет `build/Herdr Tavern.app` только после успешной компиляции, подписи и её проверки. Художественные мастера и рецепты подготовки в bundle не входят.

В release-профиле Cargo явно задано `strip = "none"`: это обходит [ошибку LLVM при удалении debug-информации из dylib](https://github.com/rust-lang/rust/issues/157750), из-за которой macOS 27 отказывается загружать Rust proc-macro с `mis-aligned LINKEDIT string pool`. Обезличивание путей при этом сохраняется.

При сборке локальные пути исходников, домашнего каталога, Cargo и инструментов Rust заменяются относительными префиксами в приложении, включая отладочную карту линкера. Доступ к файлам во время работы не меняется; происхождение ресурсов обозначается именами исходных наборов и артефактов, а не личными путями.

## Установка herdr

При каждом запуске Tavern проверяет наличие herdr. Если он не найден, приложение запрашивает разрешение скачать официальный релиз **0.9.4** с GitHub, проверяет контрольную сумму SHA256 и устанавливает файл в `~/Library/Application Support/HerdrTavern/bin/herdr`. Версия закреплена, это не `latest`; загрузка начинается только после подтверждения.

Эта установка предназначена только для Tavern и не требует прав администратора. Установщик не устанавливает herdr системно или через Homebrew, не меняет существующие установки, профили оболочки или `PATH` вне Tavern. Уже найденный herdr используется без скачивания, перезаписи или обновления.

Отмена первоначального предложения ничего не устанавливает и завершает этот запуск. Настройки «больше не спрашивать» нет: если при следующем запуске herdr по-прежнему отсутствует, предложение появится снова. После успешной установки запуск продолжается без ручного перезапуска.

Вместо этого можно установить herdr вручную по [официальной инструкции](https://github.com/herdrdev/herdr#readme) и сделать исполняемый файл доступным Tavern либо явно выбрать его через `--herdr PATH`. Неверный явно заданный путь — ошибка, а не разрешение молча выбрать или установить другой исполняемый файл.

При запуске Tavern подключается к существующей сессии herdr или запускает сервер, если его сокет отсутствует. Обнаруженный неработающий сокет автоматически не удаляется: приложение показывает ошибку подключения. Журнал запуска сервера: `~/Library/Logs/HerdrTavern/server.log`.

## Выбор сессии и сервера

Для отдельной сессии выполни из корня репозитория:

```sh
"build/Herdr Tavern.app/Contents/MacOS/HerdrTavern" --session tavern
```

| Аргумент | Назначение |
| --- | --- |
| `--session NAME` | Выбрать именованную сессию herdr. |
| `--herdr PATH` | Явно выбрать исполняемый файл herdr; неверный путь — ошибка без подмены и предложения установки. |
| `--socket PATH` | Подключиться к клиентскому сокету без автозапуска сервера. |

Без явных аргументов учитываются переменные `HERDR_SESSION`, `HERDR_SOCKET_PATH`, `HERDR_CLIENT_SOCKET_PATH` и `XDG_CONFIG_HOME`. При запуске сервера Tavern дополняет `PATH` стандартными каталогами Cargo и Homebrew, но не читает настройки оболочки и не меняет окружение уже работающего сервера.

При запуске сервера Tavern также задаёт `PI_FORCE_IMAGE_PROTOCOL=kitty`, чтобы omp отображал изображения и в новых, и в восстановленных панелях. Настройку наследуют все панели этого сервера, в том числе при подключении других клиентов. Уже работающие серверы и процессы, включая серверы, доступные через `--socket`, не меняются: для применения настройки их нужно перезапустить с этой переменной.

## Настройка и работа

**Язык.** Открой настройки через `⌘,` или кнопку инструментов и выбери **English** или **Русский**. Начальный язык — английский; выбор сохраняется. Интерфейс обновляется сразу, без перезапуска Tavern, переподключения или потери herdr-сессий. Терминальный вывод и внешние программы сохраняют собственный язык.

**Агенты и звуки.** В разделе «Агенты» можно установить, обновить и удалить интеграции herdr; сами программы агентов и доступ к моделям настраиваются отдельно. После изменения интеграции перезапусти соответствующий агент. В разделе «Звуки» доступны выключатели, громкость, прослушивание и замена звуков своими файлами.

**Конфигурация herdr.** Меню **herdr** позволяет менять доступные настройки, открывать полный `config.toml`, проверять и перезагружать его. Файл общий для локальных сессий. Темы и индикаторы herdr не меняют оформление Tavern; звуки Tavern настраиваются отдельно. При `--socket` меню всё равно работает с локальной конфигурацией, которая может отличаться от конфигурации подключённого сервера. Подробнее — в [документации herdr](https://herdr.dev/docs/configuration/).

**Вставка и файлы.** `⌘V` вставляет текст; прикрепление изображений зависит от программы внутри терминала. Перетаскивание из Finder вставляет пути в панель под курсором, без отправки Enter и без загрузки файлов.

**Разделение панелей.** `⌘D` разделяет панель в фокусе вправо, `⌘⇧W` — вниз. Новая панель получает фокус.

**Закрытие.** `⌘W` закрывает панель в фокусе после подтверждения завершения её процессов. Чтобы закрыть окно Tavern без завершения сессии herdr и её процессов, используй кнопку закрытия окна или команду меню «Окно».

**Уведомления.** Разрешение на баннеры задаётся в **Системные настройки → Уведомления → Herdr Tavern**. Отказ не отключает звуки и отметки непрочитанного на карточках агентов.

Tavern не воспроизводит весь интерфейс herdr: поддержка пользовательских `keys.command` не означает перенос всех встроенных сочетаний его терминального интерфейса.

## Разработка

Интерфейс написан на Swift/AppKit, клиент и выделенный протокол — на Rust. Исходники находятся в `app/` и `crates/`, проверки — в `tests/` и Rust-пакетах.

Не добавляй в Git локальные `.env`, приватные ключи и экспорты сертификатов с ключами (`.p12`/`.pfx`): они исключены через `.gitignore`, как и сборки и кэши. Для обезличенных примеров предусмотрены `.env.example` и `.env.sample`. Исключения не удаляют уже отслеживаемые файлы или данные из истории Git.

Из корня репозитория:

```sh
cargo +stable test --locked --workspace
```

Swift-проверки — самостоятельные драйверы, а не Xcode/XCTest-проект. Обновление выделенного протокола выполняется отдельно от обычной сборки; закреплённая ревизия и происхождение записаны в [PROVENANCE.json](../crates/herdr-protocol/PROVENANCE.json).

## Необязательная офлайн-подготовка ресурсов

Сохранённые художественные мастера находятся в `resources/Textures/Sources/`, `resources/Textures/TavernVisuals/sources/` и `resources/Icons/Sources/`. Подготовка ресурсов выполняется отдельно от обычной сборки и не обращается к сервису генерации изображений.

- `tools/prepare-{app-icon,button-families,sidebar-cabinet,scroller-material}.py` готовят иконку и используемые текстуры интерфейса; нужны Python 3 и Pillow.
- `resources/Textures/TavernVisuals/tools/prepare-selection.py` дополнительно требует NumPy и пишет три карты закладки непосредственно в `TavernVisuals/sprites/`.
- `resources/Textures/TavernVisuals/tools/prepare-chained-talismans.py` использует Pillow и пишет шесть RGBA-спрайтов непосредственно в `TavernVisuals/chained/`, без неиспользуемых карт высоты/материалов и demo-превью.

Запускай рецепт через `python3`, указывая путь относительно корня репозитория. Рецепты создают только изображения: JSON-манифесты не требуются и не записываются. Мастера доступны только для чтения, кроме явного импорта цепных талисманов с `--concepts DIR`: он копирует `talismans-chain-v1.webp` и требует отдельной актуализации сведений об источнике и правах в [NOTICE.ru](../NOTICE.ru). Это уведомление не предоставляет разрешение на распространение.

Рецепты не запускаются при сборке. В проверенном окружении рецепт закладки сохраняет прежнюю обработку, но не воспроизводит сохранённые PNG попиксельно; перед намеренной заменой готовых ресурсов сравните результат визуально.

## Оформление README

Текст шапки отрисован существующими шрифтами приложения, а не сгенерирован вместе с картинкой. Чтобы заново получить обе языковые версии, выполни из корня репозитория:

```sh
swift tools/render-readme-header.swift
```

Это необязательный инструмент оформления документации, не часть сборки приложения. Ему нужны сохранённый `docs/assets/header-art.webp` и существующие шрифты в `resources/Fonts/`. Уведомления о правах на шрифты и исходные ресурсы сохраняются: см. [NOTICE.ru](../NOTICE.ru).
